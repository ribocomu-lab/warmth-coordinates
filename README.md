# 온도의 좌표 (1단계 프로토타입)

> 새벽에 온 친구의 메시지에 답하다 보면, 내가 듣고 싶었던 말이 드러나는 대화형 자기 이해 콘텐츠  
> **한 줄 카피**: “그 말, 사실 네가 듣고 싶었던 거 아니야?”

기획안(`docs/기획안.md`)의 **1단계 프로토타입 범위(대화 화면 · 채점 · 키워드 분류 · 텍스트 결과 중심, 반전 애니메이션 및 이미지 카드 제외)**로 구현한 무서버 정적 웹사이트입니다.

## 폴더 구조

```text
/
├─ index.html              # 랜딩 + 이름 설정 + 8턴 대화 + 텍스트 결과 (단일 페이지)
├─ assets/
│  ├─ css/style.css        # 새벽 네이비 + 따뜻한 스탠드 조명 톤 반응형 스타일
│  └─ js/
│     ├─ script.js         # 모든 대본(T0~T7), 6개 위로 유형, 4분면, UI·안내 문구 단일 관리
│     ├─ scoring.js        # 채점, 키워드 분류, 동점 규칙, 말투 습관, 위기 신호 감지 순수 함수
│     ├─ chat.js           # 대화 진행, 보기→입력창 채우기·수정 추적, 대기 건너뛰기 제어
│     └─ result.js         # 텍스트 결과 렌더링, 다른 문장 다시 고르기, 로컬 데이터 삭제
├─ tests/
│  └─ scoring.test.js      # 스크립트 균형·채점·동점·분류 실패·건너뛰기·위기 감지 검증
├─ docs/
│  └─ 기획안.md
└─ README.md
```

## 로컬 서버 실행 방법

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` (또는 `http://127.0.0.1:8080`)에 접속합니다.

## 문구 수정 위치

대화 대본(`TURNS`), 6개 위로 유형(`COMFORT_TYPES`), 온도의 좌표 4분면(`QUADRANTS`), 안전·프라이버시 안내를 포함한 모든 텍스트는 **`assets/js/script.js`** 한 곳에서 관리합니다.

## 채점 및 분류 테스트 실행

```bash
node tests/scoring.test.js
```
